# SoloDesk screenshots

Captured from the deployed app on 20 October 2026 using **local demo/sample data**. These images do not show a signed-in user's workspace. Mobile captures use a simulated phone viewport.

The gallery contains **21 screenshots**, including **nine new productivity views**. Existing workspace images were refreshed for the new toolbar. All images are actual app captures; no stock images or invented interface mockups are used. The recurring invoice example is an **unsent draft**.
